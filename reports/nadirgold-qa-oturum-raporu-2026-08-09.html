4. QA Paneli (yeni geliştirme)

Lokal, bağımlılıksız Node sunucusu + tek sayfa arayüz. npm run panel → http://localhost:4646. Jira'ya karşı salt-okunur; tek yazma yolu onay diyaloğlu "Jira'ya Gönder" butonu.

Görünüm ve takip

  • 3 sekme: Test Kolonu / V2 Takip (New-Backend) / Tümü — kişiye göre gruplu, aranabilir, 60 sn'de bir tazelenen kart listesi.
  • Jira statüsü ile yerel QA verdict'i (PASS / FAIL / ERROR / TEST EDİLMEDİ / BUG) yan yana; ERROR = script/ortam hatası, ürün FAIL'i ile karışmaz.
  • Kart detayı: açıklama, yorumlar, bağlı kartlar, koşum geçmişi, AI değerlendirmesi, kanıt görüntüleri.
  • ⚠️ Statü tutarsızlığı dedektörü: kart Test/RFS'teyken bağlı blocker'ı hâlâ açıksa uyarır — ilk taramada 21 kart işaretlendi.
  • 🔔 Retest tetikleyicisi: 148 bağlı blocker izleniyor; biri Done/RFS olunca kartta "RETEST'E HAZIR" rozeti + macOS bildirimi.

V1 ↔ V2 karşılaştırma araçları

  • Canlı iframe: solda V1, sağda V2 — iki ayrı auth-enjekteli proxy (4647/4648) ile modlar izole; access_token otomatik tazelenir.
  • Adres takibi + senkron gezinme: iframe içi navigasyon üst bara yansır; bir tarafta tıklanan link diğer tarafı da götürür.
  • Snapshot + 🎯 Piksel Diff: tam sayfa görüntüler ve fark yüzdesi + kırmızı fark maskesi.
  • 🧬 API Diff: endpoint'i iki uçtan çekip alan-alan tablo: V2'de eksik / sadece V2 / tip farkı / değer farkı.
  • 📊 Sayfa analizi: başlıklar, link/görsel sayıları, kırık görseller, CDN host'ları, metin uzunluğu diff tablosu.
  • 🐞 Console yakalayıcı: iki moddaki JS hataları canlı sayaçla (NSB-2042 için hazır araç).

Jira entegrasyonu ve otomasyon

  • 🎯 Hedef çıkarma: kart metinlerinden endpoint/URL parse edilir; çipe tıklayınca GET/sayfa yan yana açılır, POST yanıtları pane'lere basılır.
  • 💬 Yorum taslağı: verdict'ten otomatik QA raporu taslağı → düzenle → kanıt seç → onayla → Jira'ya gönder.
  • ▶ Test Koştur: whitelist'li koşumlar panelden tetiklenir, log canlı akar, verdict düşünce rozet anında güncellenir (SSE).
